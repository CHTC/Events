What does it take to move an analysis from your computer to the OSPool?

This training will show how to run a data analysis script on the OSPool. We'll go through a hands-on example together and talk about the steps needed to bring your own script to the OSPool. The example will use R and .csv files, but can be generalized to most scripting languages (Python, R, Julia) and many different input file types! This is a good training for anyone who has an OSPool account and wants to move beyond basic "hello world" examples to a more realistic workflow.

### Prerequisites
* Basic machine learning concepts
* Basic understanding of HPC/HTC systems
* Experience with the command line
* Some familiarity with HTCondor is recommended but not required
